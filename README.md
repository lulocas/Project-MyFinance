# MyFinance

Sistema web de gestão financeira pessoal desenvolvido como projeto Full Stack, com o objetivo de facilitar o controle, a organização e o acompanhamento da vida financeira.

## Sobre o projeto

O MyFinance permitirá centralizar informações financeiras em um único lugar, possibilitando acompanhar receitas, despesas, contas bancárias, investimentos, reservas financeiras e cartões de crédito.

Além de ser desenvolvido para uso pessoal, o projeto tem como objetivo aprofundar conhecimentos em desenvolvimento Full Stack, especialmente em Node.js, React, TypeScript e PostgreSQL.

## Funcionalidades planejadas

- [ ] Dashboard com visão geral da situação financeira.
- [ ] Cadastro e gerenciamento de múltiplas contas.
- [ ] Registro de receitas, despesas e transferências.
- [ ] Categorias e subcategorias financeiras.
- [ ] Lançamentos recorrentes.
- [ ] Metas e reservas financeiras.
- [ ] Controle de investimentos.
- [ ] Gerenciamento de cartões de crédito e faturas.
- [ ] Relatórios e gráficos financeiros.
- [ ] Calendário de compromissos financeiros.
